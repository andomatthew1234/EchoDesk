# EchoDesk Desktop 0.2.11 for macOS: visual changelog

These four comparisons show the original Desktop layout alongside the native macOS layout in 0.2.11. Open an image to see the controls at full size.

| Page | What to look for |
| --- | --- |
| [Overview](overview-comparison.png) | The device preview sits beside brightness, appearance and connection controls when there’s room. In a narrower window the controls move underneath it. |
| [Customisation](customisation-comparison.png) | Setting labels and controls line up within each group. Appearance, time format and brightness remain easy to find as the window changes width. |
| [Set up a new device](setup-comparison.png) | USB and Wi-Fi choices share a row when there’s space and stack when there isn’t. Each choice keeps its own action with its description. |
| [Device recovery & updates](recovery-comparison.png) | The device selector and installed and available firmware versions come first. Routine updates sit apart from reinstall, repair and recovery; the action buttons align on the right. |

The [Bedside alarm examples](bedside-alarm-matrix.png) show the empty and four-alarm editors at narrow and wide sizes. Back stays above the editor in each case.

The [main review](https://github.com/andomatthew1234/EchoDesk/actions/runs/41542992127) covered **900 × 650**, **1100 × 750**, **1280 × 800** and **1440 × 900** point windows. A [second review](https://github.com/andomatthew1234/EchoDesk/actions/runs/41543158272) covered the **820 × 580** minimum, **960 × 680** and **1050 × 700**. Each ran in light and dark appearance. The screenshots show the real macOS app with a simulated device connection so the same state can be compared across sizes. No physical device was connected or flashed for these captures.
